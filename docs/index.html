方法与边界

我们检查什么

核对投资分析稿与用户提供的参考材料是否一致，识别数字、口径、证据缺失及预测性判断。不是财报审计，也不能全面判定现实世界真假。

AI与人的分工

外部AI拆解主张、理解语义和匹配证据；程序检查引用存在性、原稿位置、任务一致性，并复算数字；人工核查来源、口径及语义后作出处理决定。

免费与数据

不调用任何收费API。AI由用户在已有工具中使用，其账号、额度与条款以该工具为准。本站不自动传输文本到外部AI。扶摇、iFinD、自动AI与联网检索尚未接通。

如何读结论

“支持”只说明与提交材料一致；“冲突”说明原文或数字不一致；“证据不足”不能当成否定；观点与推断不能作为已证实事实。来源日期过久会提醒，但不自动判历史材料无效。

失败、保存与限制

空结果、不完整JSON、假引用、旧任务和无效算式均明确报错。记录在用户完成复核后保存至本机，清浏览器数据会丢失。外部AI身份未认证，逐字引用不保证语义正确。不输出确定性涨跌、收益承诺或直接买卖建议；AI仍可能漏判，人工复核不可省略。

效果验证

当前已验证程序与单例协作流程，没有证明准确率或效率提升。后续需独立人工标注集与人工流程对照；手动传递JSON增加操作负担，属于已知不足。

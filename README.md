# 证据台 v0.3

## 目标用户与任务
投资内容编辑、研究助理。发布前核对分析稿与参考财报/公告的一致性，发现数字、口径与无依据主张。问题假设尚未经过真实用户访谈。

## 启动与测试
要求Node.js 22+，无需安装依赖。解压后进入source目录：

- `npm run dev`：在http://localhost:4173启动本地预览。
- `npm test`：运行30项代码测试。
- `npm run build`：生成dist/server/index.js。
- `npm run validate`：验证构建产物。

默认协作流程无需环境变量、API密钥或额外API费用。外部AI工具的账号、额度和条款以该工具为准。线上部署可使用支持Cloudflare Worker ESM的宿主，需自行配置访问权限。

## 真实工作流
输入稿件和参考材料→生成带输入标识的任务→复制给现有AI工具→导入JSON→验证引用与复算数字→逐项人工复核→结束并保存本机记录→导出报告。
案例、文件导入和未开发功能集中在更多菜单。参考材料、证据与计算默认折叠。核查结束不代表稿件已经修改或可以发布。

## AI与程序角色
外部LLM拆句、理解语义、匹配证据、区分事实与推断。程序检查主张是否在原稿、引用是否在材料、任务是否匹配，执行growth/ratio/pp计算。人工检查来源真实性、日期、单位、统计口径和发布风险。
浏览器侧校验用于可用性与防误操作，不是防篡改安全边界；任务标识非加密，不是身份签名。

## 为什么需要AI
预期增量是同义表达匹配与推断识别。规则适合数值复算与格式检查，搜索帮助找来源，人工决定语义和口径。此增量尚未通过独立评测证明。手工往返JSON增加用户负担，需与直接聊天及人工核查比较。

## 数据与风险
参考材料由用户粘贴或导入TXT/MD，链接不自动抓取。支持、冲突、证据不足、观点推断、发布风险分别展示。未找到证据不等于事实为假。
Apple案例参考其2025财年第四季度公开未经审计合并财务报表第1页；披露日期2025-10-30、单位百万美元，链接随材料保存；仅收入行摘录，不代表最新财报。测试稿件有意包含错误。
构造案例公司与数据均虚构，结果预设并标记。扶摇/iFinD未接通。
默认协作流程在浏览器处理，不自动发往模型服务商；用户自行粘贴给外部AI前应确认数据使用权限。完成记录存本机，清缓存会丢失；共享浏览器可能看到记录。无需填写持仓或个人信息。

## 失败条件
空材料、空结果、截断或不合法JSON、旧任务、缺引用、假引用、分母为零等明确报错，不生成正常结论。引用存在只证明字符串一致，不证明语义正确。
不提供确定性涨跌预测、收益承诺或直接买卖建议。外部模型可能漏检，人工复核不可省略。

## 兼容保留代码与环境变量
源码保留了尚未启用的服务端模型适配器，变量名OPENAI_API_KEY与OPENAI_MODEL；当前均未配置、未验证真实请求，默认UI不调用它。不要写入真实凭据或启用计费。

## 已知边界与后续验证
网站自动推理、联网取证、金融接口、PDF解析、云存储、多人协作、独立准确率评测和真实用户效率测试未完成。报告全文预览和复制保存已验证；Markdown下载事件仍未捕获，需实际确认。
建议使用至少30条独立人工标注主张，测覆盖率、类别F1、引用匹配率、复算准确率；同题比较人工、规则和AI辅助用时与错误数。当前没有效率或准确率提升数字。
